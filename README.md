# PDF Editor Application

## About the Project

I developed this PDF Editor Application using Python as part of my internship project.

The main purpose of this project is to make working with PDF files easier. The application provides a simple graphical interface where users can select files and perform different PDF operations without needing to type commands.

## Features

The application includes the following features:

1. Merge PDFs – Combine multiple PDF files into a single file.
2. Split PDF – Split a PDF into separate pages.
3. Rotate PDF – Rotate PDF pages by 90, 180, or 270 degrees.
4. Delete Pages – Remove unwanted pages from a PDF.
5. Reorder Pages – Arrange PDF pages in the required order.
6. Extract Text – Extract text from a PDF and save it in a text file.
7. Images to PDF – Convert multiple images into a single PDF.
8. PDF to Images – Convert PDF pages into PNG images.

## Technologies Used

- Python
- Tkinter for the graphical user interface
- PyMuPDF for PDF operations
- Pillow for image processing
- Visual Studio Code for development

## Project Structure

The project contains the following files:

- `main.py` – Contains the graphical user interface.
- `pdf_operations.py` – Contains the functions used to process PDF files.
- `requirements.txt` – Lists the required Python libraries.
- `README.md` – Contains the project documentation.

## Installation

First, make sure Python is installed on your computer.

Open the project folder in Visual Studio Code and open the terminal.

Install the required libraries by running:

    python -m pip install -r requirements.txt

## How to Run the Application

After installing the required libraries, run the following command in the terminal:

    python main.py

The PDF Editor window will open. Select the operation you want to perform and follow the instructions displayed by the application.
